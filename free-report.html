How to use this site

  1. Start on the dashboard public table, then the finding card.
  2. Open Awards. Two strips: Follow the money (14 flagship) and New primes (46). Filter nuclear / magnets / chips / defense. Watchlist filter is local-only.
  3. Read the status tag before the dollar: FINAL, CONDITIONAL, LOI, UCA. On LMT/RTX UCAs, read obligated vs face.
  4. Ticker pages and award permalinks are static. Historical returns are close-to-close, not forecasts.
